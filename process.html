미니창고짐 홈페이지 신청·결제 개편 안내

고객이 홈페이지 배치도에서 창고를 고르고, 신청부터 결제·연장까지 직접 마칠 수 있게 바꿨습니다. 결제가 끝나는 순간 계약 기록, 지점 장부 기재, 배치도 '사용중' 표시, 알림 메일까지 자동으로 처리됩니다.

1차 오픈: 신내 1호점 · 신대방점 실제 결제 시험 완료 (신규 · 연장 · 취소 · 메일) 지점 원본 시트 자동 기재: 신내 1호점 적용 카카오 알림톡 운영 중

AS-IS / TO-BE 한눈에

AS-IS · 이전
  1. 고객이 홈페이지에서 이용신청서만 작성 (회원가입 없음)
  2. 매니저가 신청 내용 확인
  3. 매니저가 사이다페이 결제 링크를 만들어 1:1로 발송
  4. 고객 결제 → 매니저가 확인 후 지점 시트에 직접 기록 · 배치도 사용중 체크
  5. 연장 때마다 매니저가 다시 링크 발송

신청만 하고 결제하지 않은 건이 섞이고, 고객은 남은 기간·영수증을 매니저에게 물어봐야 알 수 있었습니다.

TO-BE · 이후
  1. 고객이 배치도에서 빈 창고 선택 → 회원 로그인
  2. 신청서 작성 (회원 정보 자동 입력) → 바로 사이다페이 결제
  3. 결제 완료 순간 결제서버 기록 · 결제현황 시트 · 지점 원본 시트 자동 기록
  4. 배치도에 '사용중' 자동 표시 · 같은 창고 재신청 차단
  5. 고객·관리자 결제 완료 메일 자동 발송, 연장은 마이페이지에서 직접

매니저는 결제된 건을 메일로 확인하고 출입 안내만 하면 됩니다. 결제 금액은 서버가 배치도 요금으로 계산해 고객이 바꿀 수 없습니다.

결제가 끝나는 순간 자동으로 일어나는 일

즉시
결제서버 기록에 '결제완료'같은 창고의 다른 결제창은 닫히고, 그 창고 신규 신청은 서버가 막습니다.
즉시
지점 원본 시트 기재그 창고 줄에 사용중 체크 · 계약일 · 전화 · 성함 · 검색어 · 사이다(홈피). 조건이 어긋나면 쓰지 않고 관리자 메일에 '확인 필요'로 알립니다.
즉시
결제 완료 메일고객에게 결제 확인 메일, 관리자에게 고객 정보·원본 시트 기재 결과가 담긴 운영알림.
몇 초 안
홈페이지 결제현황 시트 갱신매니저가 보는 시트. 이전에는 5분마다 갱신해서 결제 직후 바로 보이지 않았습니다.
1분 안
배치도에 '사용중' 표시배치도가 원본 시트를 1분마다 다시 읽습니다. 열려 있던 화면은 새로고침하면 바로 바뀝니다.

서버가 쓰는 칸은 원본 시트의 A · O~S열뿐입니다. 월별 금액·색·메모 등 정산 기재는 지금처럼 정산 담당이 합니다.

고객 화면 — 신규 신청부터 결제까지

아래 화면은 10/12 실제 결제로 시험한 화면입니다. 신규와 연장을 따로 캡처해 창고 번호(S 11, S 9)가 다르고, 연장 시험을 위해 이용 날짜를 시트에서 한 달 앞당겼습니다. 연락처는 가렸습니다.

1

배치도에서 창고 선택 → 신청 화면

  • 지점 배치도에서 '계약가능' 창고를 누르면 그 자리에서 신청 화면이 열립니다.
  • 로그인하지 않았으면 로그인 안내가 뜨고, 로그인 후 고르던 창고의 신청 화면으로 돌아옵니다.
  • 네이버·구글 간편가입도 됩니다.
2

신청서 작성

  • 지점·창고·요금은 배치도에서 넘어와 고칠 수 없습니다.
  • 이름·연락처는 회원 정보에서 자동으로 채워집니다.
  • 결제방식(월 결제 / 6개월·12개월 선결제)을 고르면 결제 금액이 바로 보입니다.
  • 계약 안내·환불 규정 등 필수 안내는 내용을 끝까지 읽어야 동의할 수 있습니다.
3

사이다페이 결제

  • [신청하기]를 누르면 바로 사이다페이 결제 화면으로 넘어갑니다.
  • 상품명은 S11_12개월분 형식(연장은 ' (연장)')으로 찍혀 정산 때 창고와 바로 대조됩니다. 판매자는 해당 지점으로 표시됩니다.
  • 카드결제 · 카카오페이 · 페이코를 쓸 수 있습니다.
금액은 서버가 계산 — 고객이 바꿀 수 없음
4

카드 결제

  • 카드사를 고르고 결제를 마칩니다.
  • 카드 내역에는 결제대행사 (주)유디아이디로 표시된다는 안내를 신청서에 미리 넣었습니다.
5

결제 완료 → 홈페이지로 복귀

  • 결제가 끝나면 신청하던 배치도 페이지로 돌아와 '결제가 완료되었습니다' 안내가 뜹니다.
  • 결제를 중간에 그만두고 돌아오면 '다시 신청 / 신청 취소'를 묻는 안내가 대신 뜹니다.
계약 · 결제현황 · 지점 원본 시트 자동 기록
6

마이페이지에 이용 내역

  • 결제한 계약이 회원 마이페이지에 바로 나타납니다.
  • 상태는 이용중 · 이용예정 · 기간만료 · 이용종료 · 취소됨으로 구분되고, 상태별로 걸러 볼 수 있습니다.
  • [영수증 보기]로 카드 영수증을 언제든 다시 볼 수 있습니다.
7

결제 완료 메일

  • 고객에게 결제 확인 메일이 자동으로 갑니다 (회원 이메일).
  • 같은 순간 관리자에게도 고객 이름·연락처·창고·금액과 원본 시트 기재 결과가 담긴 운영알림 메일이 갑니다. [결제현황 시트 열기] · [지점시트 열기] 버튼이 있습니다.
  • 보내는 주소는 beyondspace.zim@gmail.com (챗봇 알림과 같은 계정)입니다.

8

종료일이 다가오면 [연장하기]

  • 마이페이지 계약 카드에 [연장하기] 버튼이 생깁니다.
  • 월 결제는 종료 7일 전, 선결제는 종료 30일 전부터 종료 후 14일까지 보입니다.
  • 남은 날짜가 카드에 함께 표시됩니다.
9

연장 결제

  • 갱신일은 기존 종료일 다음날로 자동 지정되어 고객이 바꿀 수 없습니다.
  • 결제방식(월 결제 / 선결제)을 다시 고를 수 있습니다.
  • 기존 계약 조건 안내를 끝까지 읽고 동의해야 결제할 수 있습니다.
  • 계약한 본인 계정으로만 연장할 수 있습니다.
10

연장 후 마이페이지

  • 지금 기간 카드에 '다음 기간 연장 완료 — ○월 ○일까지'가 표시됩니다.
  • 다음 기간은 '연장' 표시와 함께 '이용예정' 카드로 따로 쌓입니다.
연장 계약 기록 + 원본 시트 계약일 자동 갱신
11

연장 완료 메일

  • '연장 결제가 완료되었습니다' 메일이 고객에게, 연장 알림이 관리자에게 갑니다.

매니저 아침 운영알림

  • 매일 아침 그날 챙길 일만 한 통으로 보냅니다. 챙길 일이 없는 날은 보내지 않습니다.
  • 맨 위에 연장 안내 · 새 결제 · 기간만료 · 확인 필요 건수를 보여 주고, 아래에 고객별 카드로 정리합니다.
  • 카드마다 할 일을 색으로 구분합니다. 초록은 자동 처리돼 할 일 없음, 주황은 매니저가 할 일입니다.
매니저가 시트를 뒤지지 않아도 됨
13

새 결제 · 기간만료 · 확인 필요

  • 종료일이 지났는데 정리되지 않은 고객, 이중 결제 의심 같은 확인 필요 건을 따로 모읍니다.
  • 하단에서 결제현황 시트와 지점별 원본 시트를 바로 열 수 있습니다 (관리자 권한이 있는 사람만 열림).
14

시트 바로가기

  • 결제 완료 운영알림에도 [지점시트 열기] 버튼이 있습니다.
15

연장매달·만기마다 결제 링크 발송, 계약일 수정고객이 마이페이지에서 결제, 원본 시트 계약일 자동 갱신

AS-IS
  1. 비회원, 지점 시트로만 관리
  2. 만기마다 매니저가 결제 링크 발송
  3. 남은 기간은 고객센터에 문의
TO-BE
  1. 연장 링크를 자동으로 만들어 카카오 알림톡으로 발송 (준비 중)
  2. 고객이 링크에서 회원가입 → 연장 결제
  3. 이때부터 회원 계약 — 다음 연장은 마이페이지 · 알림톡으로

항목상태내용

고객 마이페이지운영 중고객이 이용 기간 · 남은 날짜 · 영수증을 직접 확인

결제 완료 알림 메일운영 중결제 즉시 고객에게 확인 메일, 매니저에게 고객 정보가 담긴 알림 메일
매니저용 결제 현황 시트운영 중홈페이지 결제가 지점별로 바로 정리됨 (매니저는 보기 전용)
지점 장부 자동 기재 · 배치도 '사용중' 자동신내 1호점 운영 중결제되면 지점 원본 시트에 고객 정보가 들어가고 배치도가 '사용중'으로 바뀜. 다른 지점은 시트 연결 후 적용
매니저 아침 알림 메일운영 중매일 아침 연장 안내 대상 · 새 결제 · 기간만료 · 확인 필요 건을 한 통으로 정리
고객 연장 안내 메일운영 중종료일이 다가오면 고객에게 자동 발송 (선결제 30·7일 전, 월결제 7일 전). 연장하지 않을 고객은 카카오톡 상담으로 연결
